# 共享文档：标签信息不全提醒与补充流程

## 要做的事

### 1. 标签缺失提醒
- 在提单表单「问题共享文档设置」里，已勾选的标签如果其末级信息超过一半为空（未填写/未选择/未上传），标签右上角出现一个感叹号角标。
- 只要存在这样的标签，标签区下方出现一条提示：「当前问题缺少有效信息，可能影响问题定位」，并给出三个操作：补充信息 / 提单给他人补充 / 暂时跳过。
- 「暂时跳过」后本次提单不再显示这条提示（角标保留），换项目或重新勾选后可再次出现。

### 2. 补充信息（侧滑抽屉）
- 点「补充信息」从右侧滑出抽屉，里面就是现有的项目信息编辑界面（与项目信息管理编辑页一致的节点编辑能力）。
- 编辑内容直接保存到云端，与项目详情页共用同一份数据。
- 抽屉关闭或保存后，缺失判定重新计算，共享文档中的「项目背景信息」自动刷新为最新内容。

### 3. 提单给他人补充（示例态）
- 点「提单给他人补充」弹出一个小窗：显示待补充的标签清单，选择一位接单人，填写备注。
- 提交后提示「补充工单已发送」，缺失提示行变为「已提单待他人补充」，并在共享文档的自动区块顶部标注哪些标签正在等待补充。
- 本期不落库，仅示例。

## 技术说明
- 新增 `src/lib/node-completeness.ts`：由 `ProjectNode[]` 计算每个一级标签的末级节点总数/空值数，空值率 > 50% 记为不完整。
- 复用 `ProjectInformationTree` 组件放进 `@/components/ui/sheet`（side="right"）抽屉，传入 `projectCode`/`projectName`；保存走已有 `updateProjectNode` 等 server fn，保存后 invalidate `["project-nodes", projectCode]`，`TicketCreateSheet` 的文档自动段随之重算。
- `TicketCreateSheet.tsx` 增加 `skippedWarning`、`pendingAssignTags`、`supplementOpen` 三个本地 state；标签按钮加相对定位的感叹号角标。
- 补充工单弹窗用 Dialog + 接单人下拉（取 `src/data/mock.ts` 现有人员示例数据），仅 toast 提示。
- `buildAutoSection` 增加可选的「待补充标签」参数，在自动区块顶部输出一行提示，手写补充段落仍不被覆盖。
- 沿用现有黑白灰 + 蒂芙尼蓝语义色与 shadcn 组件，手机优先。

## 验收
- 勾选一个信息大量为空的标签 → 角标 + 提示行出现。
- 「补充信息」抽屉里补齐内容并保存 → 角标消失、共享文档背景信息同步更新。
- 「提单给他人补充」→ 选接单人提交后提示成功，文档标注等待补充。
