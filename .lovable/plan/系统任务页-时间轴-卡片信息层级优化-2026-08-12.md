# 系统任务页：时间轴 + 卡片信息层级优化

## 1. “待我处理”下的按天时间轴
选中“待我处理”筛选时，列表切换为时间轴布局（其他筛选保持现有列表）：

- 左侧一列固定宽度的日期轴：显示日期（如 `08-07`）与竖向虚线连接，同一天的工单归为一组。
- 每组内按紧急度排序：紧急 → 高 → 中 → 低，紧急的排在上面。
- 组与组之间用浅色虚线分隔，日期文字灰色、数字略大，参考图中左侧时间列的节奏。
- 卡片本身沿用现有工单卡片样式，只是右移让出时间轴空间。

```text
08-07  ┆ ┌───────────────────────┐
       ┆ │ 紧急 · 工单标题        │
       ┆ └───────────────────────┘
       ┆ ┌───────────────────────┐
       ┆ │ 中 · 工单标题          │
- - - -┆- - - - - - - - - - - - - -
08-06  ┆ ┌───────────────────────┐
```

## 2. 参与讨论人头像
在发起人与处理人之间，插入一排小一号（比现有头像小）的圆形姓氏圈，表示其他参与讨论的人：

- 背景统一浅灰，文字深灰，取消所有彩色。
- 重叠排列，最多显示 3 个，超出显示 `+N`。
- 发起人/处理人头像同样去掉蓝色背景，改为浅灰底深灰字，保持整页无彩色头像。
- 参与人数据在 mock 数据中为每条工单补一个 `participants` 字段（姓名数组）。

## 3. 筛选按钮角标
每个筛选按钮（全部／项目相关／待我处理…）右上角加一个圆形数字角标：

- 深蓝底（blue-1）、白色数字，小号加粗，超过 99 显示 `99+`。
- 数量为 0 时不显示角标。
- 数量由当前 mock 工单按该筛选规则统计得出。

## 4. 卡片文字层级（苹果式极简）
工单卡片内除状态外全部去色，只用字号与字重区分：

- 工单名：最大、最重（约 16px / semibold），信息层级第一。
- 状态（处理中/进行中等）：唯一带颜色的文字，用蓝阶文字色，去掉色块背景，改为纯文字或极淡底。
- 优先级、类型、编号、项目名、日期、发起人/处理人：统一灰阶，靠字号（11–13px）和字重区分主次。
- 字体族在设计系统中优先使用苹果系统字体（-apple-system / SF Pro / PingFang SC），保留现有圆润中文回退。
