# 项目详情页重构

按截图的信息结构新建「项目详情」页，视觉沿用现有 UI 体系：黑白灰为主，蓝色仅作重点点缀，方圆角卡片、苹果系统字体。

## 入口

- 项目进度管理列表中的每张项目卡片可点击，进入 `/projects/{code}` 详情页。
- 详情页顶部沿用统一的返回导航条（标题：项目详情）。

## 页面结构（自上而下）

1. **同步条**：浅灰底细条，显示「企业微信实时数据 · 上次同步 00:05:52 · 每5分钟自动刷新」，右侧「立即同步」为蓝色文字按钮（唯一蓝色点缀）。
2. **项目概览卡**：项目名称（加粗大字）、项目编号与企业微信记录ID（灰色小字）、右上角标签（如「搬运效率分析」用灰色标签、「重要紧急」用蓝色标签，不用红色）；项目经理 / 对接人两行；项目时间进度条（灰底 + 蓝色进度，右侧蓝色百分比）；部署时间 / 近期交付 / 最终交付三列。
3. **项目基础画像卡**：字段列表（项目名称、项目编号、内部编号、项目描述、项目类型、项目区域/地点、总车数、车型&车数、控制器选择、系统/外设对接、服务器部署、部署版本）。每项为「灰色小标签 + 浅灰输入行」，右侧统一为灰色编辑图标或箭头，去掉截图里的黄色铅笔。
4. **项目生命周期卡**：项目阶段选择行 + 15 个阶段的竖向时间轴。已完成为深灰实心勾、进行中为蓝色圆环（当前阶段唯一高亮）、待开始为浅灰空心圆；右侧「+ 补充说明」改为浅灰底灰字小按钮。
5. **责任体系卡**：销售 / 售前 / 项目经理 / 实施工程师 / 人员计划，同字段行样式。
6. **风险管理卡**：风险承接、特别关注、风险和任务描述、项目管理策略、预期走向，末尾「项目文档」上传方块（浅灰底 + 灰色加号）。

## 视觉规则

- 卡片：`surface-card`，卡内分组用细分隔线，圆角与全站一致。
- 字段行：`bg-secondary/60` 浅灰底、方圆角、13px 文本，标签 11px 灰色。
- 蓝色仅用于：立即同步、进度条与百分比、重要紧急标签、当前进行中阶段圆点。其他一律黑白灰。

## 技术说明

- 新增 `src/routes/projects.$id.tsx`（TanStack 文件路由，含独立 head 元信息）。
- 在 `src/data/mock.ts` 增加 `projectDetail` 模拟数据（字段项、生命周期阶段、责任体系、风险管理）。
- 字段行、区块标题等抽为 `src/components/ProjectDetailBits.tsx` 的小组件复用。
- `src/routes/projects.tsx` 的卡片包一层 `Link`。
