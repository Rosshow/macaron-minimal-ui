# 按新树形图重建「项目信息管理」的信息结构

功能、交互、样式全部不变，只把预设的信息节点内容换成新图那一版。

## 一级标签（12 个，按图中顺序）

基础信息、硬件、车端软件、调度软件、网络信息、服务器部署、环境、业务系统、业务流程、人员信息、项目特性、项目配置、项目定制

（图中共 13 个一级分支，均保留。）

## 各分支内容

- 基础信息：客户信息；订单信息 → ERP；评审信息；项目区域/地点（大陆 China Mainland、亚洲 Asia、欧洲 Europe、北美 North America、南美 South America、非洲 Africa）；项目类型（受关注项目、大客户项目、展会/演示项目、展厅项目、PK 项目、试点项目、试用项目、内部/测试项目）；进厂要求 → 着装、预约信息
- 硬件：车辆 → 车型1（数量）、车型2（数量）；载具类型（托盘、料笼、料架、料车）
- 车端软件：控制器品牌（自研、睿芯行、利科钛、海康、华睿、中兴、科聪）；软件版本；数据同步方式；是否已与 USP 对接过（是/否）
- 调度软件：版本 → 子模块 → 调度配置、通用配置；lincense → 到期时间、续期记录
- 网络信息：外网；公网 ip → 服务器参数配置；远程方式 → SSH（IP、端口）、Todesk（远程码、密码）、AngDek（远程码、密码），密码可选动态/静态
- 服务器部署：中力服务器、客户服务器、云服务器，各带「是否与其他系统共用」
- 环境：地图布局（CAD 源文件 → 库位、库区形式/数量；AGV 路线动线；通道与托盘间距尺寸）；外设（电梯 → 厂家品牌（协议）：Modbus Tcp / ST / 中力PLC；自动门、呼叫器、输送线/辊筒线、红绿灯、机械臂、码垛机/叠盘机、缠膜机、光电、无外设声明、其他（自定义））
- 业务系统：系统 → DAS、客户 WMS、客户 MES/ERP、客户系统（其他上层系统）、数字孪生（接口协议 → 接口标准、是否对接；ip/url）、PDA、平板
- 业务流程：搬运场景 → 搬运类型（线边搬运、仓储搬运、电梯接驳、室外搬运）、装卸、分拣；节拍 → 节拍、效率要求数值/无效率声明；物料类型
- 人员信息：客户对象、实施、车端、调度、业务、项目经理、销售、售前、集成商
- 项目特性：风险点（数据同步错误、公司评审不通过、缺前置承接、高风险承接、中风险承接、低风险承接）；注意事项；时间线 → 大节点（售前方案、签单洽谈、已签合同、出厂测试、即将进场、延期进场、正在实施、实施暂停、实施运行、试运行中、验收运营、项目结束）、小节点
- 项目配置：识别
- 项目定制：接口；大屏 → 页面；功能

## 层级处理规则（页面最多 4 层）

图中的「可选值清单」不再做成第 5 层节点，而是用现有的「下拉选择」内容形式挂在对应末级节点上，例如：

- 项目区域/地点、项目类型、载具类型、控制器品牌、搬运类型、厂家品牌（协议）→ 下拉选择，选项即图中列表
- 是否已与 USP 对接过、是否与其他系统共用、是否对接 → 下拉选择（是/否）
- Todesk / AngDek 的「密码」→ 下拉选择（动态密码、静态密码），另配「远程码」文字节点

这样既完整保留图中所有信息，又不超过 4 层。

## 不改动的部分

节点卡片样式、缩进与配色、折叠、标签筛选、编辑页的增删改/拖动、上传文件与图片、编辑历史入口、Markdown 浏览态、四张卡片布局全部保持原样。

## 技术说明

- 新增一条数据库迁移：清空并按上述结构重新写入 `project_nodes` 的预设数据，覆盖现有的 8 个项目编码（AJBQCS、100、13、16、17、18、19、92）。已有的人工填写内容会被这次重置覆盖。
- 末级节点的 `content_type` 按上表设为 `text` 或 `select`；`select` 节点的 `value` 写入 `{ options: [...], selected: "" }`，与现有组件读取方式一致。
- 不改动 `project_nodes` 表结构、服务端函数与任何组件文件。
