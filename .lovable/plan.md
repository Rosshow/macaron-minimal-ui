# 可拖动的「转工单」悬浮按钮

## 目标
在对话页新增一个独立的圆形悬浮按钮「转工单」，半透明蓝底白字（白色图标），可以按住拖动到页面任意位置，与底部输入框及其周边按钮完全独立、互不影响。

## 方案
1. 新建组件 `src/components/FloatingTicketButton.tsx`
   - 圆形按钮（约 52px），`fixed` 定位，层级高于底部输入栏。
   - 样式：半透明蒂芙尼蓝底（约 70% 不透明度）+ 白色图标/文字，柔和阴影，轻微毛玻璃。
   - 内容：图标 + 「转工单」二字（图标使用 Ticket 类图标）。
2. 拖动交互
   - 使用 pointer 事件（同时支持触屏与鼠标）：按住拖动，松手停在当前位置。
   - 位置以 state 保存，限制在视口内（含安全边距），窗口尺寸变化时自动收回边界内。
   - 拖动过程中禁用页面选中与滚动干扰；移动距离小于阈值（约 4px）视为点击，触发「转工单」动作，否则不触发点击。
   - 默认初始位置：右侧、底部输入栏上方一点，不遮挡发送按钮。
3. 接入
   - 在 `src/routes/index.tsx` 中渲染该组件，不改动现有底部输入栏与气泡按钮的任何结构与样式。

## 说明
点击行为暂为占位（后续可接生成工单逻辑），不改动其他页面与全局样式。

## 验收
- 按住可拖动到页面任意位置，松手保持；不影响输入框及其左右按钮的点击。
- 样式为半透明蓝底白字圆形按钮，风格与现有极简黑白灰 + 蒂芙尼蓝一致。
