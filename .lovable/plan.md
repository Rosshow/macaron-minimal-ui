# 数据管理页面（新增路由）

在后台管理「更多功能」里点击「数据管理」，进入一个全新的数据导入页面，参考图实现，现有页面全部不动。

## 页面结构（自上而下）

1. 项目选择器：一张卡片，左侧「请选择项目」占位文字，右侧箭头，点击弹出与项目授权页一致的项目选择抽屉（复用同一份项目列表）。选中后显示项目名与编号。
2. 标签切换：「文件导入 / JSON导入」两个等宽标签，选中项为蓝色文字 + 下方蓝色短下划线，未选中为灰色。
3. 文件导入面板：一个方圆角的虚线/浅灰「+」上传块，下方一行灰色说明文字「上传 数据包文件（.bz2 或 .json，含 GroupEfficiency 等指标数据），选定项目后上传」。未选择项目时上传块置灰不可点；选择项目后可点击选择文件，选中文件后在下方以列表显示文件名与大小，可删除，并提供「开始导入」按钮（前端模拟，toast 提示）。
4. JSON导入面板：多行文本框粘贴 JSON + 「校验并导入」按钮，同样在未选项目时禁用，格式错误给出 toast 提示。

配色沿用现有体系：黑白灰为主，蓝色仅用于选中标签、下划线与主按钮。

## 技术细节

- 新增路由文件 `src/routes/data.tsx`（URL `/data`），使用 `createFileRoute("/data")`，含独立 `head()` 元信息。
- 页面用 `PageShell` 包裹，保持与其他页面一致的头部与返回。
- 项目选择抽屉复用 `@/components/ui/sheet`，项目列表沿用 `src/data/mock.ts` 中现有数据。
- 文件选择用隐藏的 `<input type="file">`，纯前端状态，不涉及后端上传。
- 修改 `src/routes/admin.tsx` 中「数据管理」入口的 `to` 由 `/projects` 改为 `/data`，其余入口不变。
