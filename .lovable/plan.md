# 项目授权页重构（统一风格）

把上传的三张截图（项目导入 / 项目授权 / licences 授权 / 人员授权，以及折叠态）重做成与现有 UI 一致的页面：黑白灰为主、蒂芙尼蓝仅作点缀、苹果系统字体、方圆角、surface-card 半透明卡片。

## 页面位置

新增路由 `/projects/$id/auth`（文件 `src/routes/projects.$id.auth.tsx`），在项目详情页底部加一个「项目授权管理」入口卡片跳转过去。原详情页（画像 / 生命周期 / 责任体系 / 风险管理）保持不变。

## 结构（自上而下，全部为可折叠 SectionCard）

1. 项目导入（折叠）
   - 展开后是两个分段按钮：USP项目 / 其他项目。选中态用深色底白字，未选中为浅灰底灰字（不再用大面积蓝色）。
2. 项目授权（折叠）
   - 一行项目条目：项目名（加粗）+ 项目代码（灰色小字）+ 右侧箭头，点击进入选择。
3. 项目 licences 授权（折叠）
   - 头部：项目名 + 「授权记录 (5)」计数徽章（灰底白字，与工单角标一致）。
   - 每条记录一张卡片：授权码（等宽 tabular 字体，加粗，超长省略）、机器码 / 有效期 / 申请人 / 允许最大车数 用统一的 label-value 行；右侧「复制」为浅灰底小按钮，「撤销」为描边小按钮（危险色仅用细边框，不用红底）。
   - 「申请授权码」表单卡：机器码输入、起止日期两列、允许最大车数（必填星号用灰色），底部主按钮「申请授权码」用蓝底白字（页面唯一的实心蓝按钮）。
4. 项目人员授权（折叠）
   - 头部：「已关联人员 (6)」+ 灰色提示「长按卡片可移除」+ 右侧「添加关联人员」描边按钮。
   - 每行：姓名（加粗）左对齐，右侧 wechat id（灰色）· 角色标签（浅灰底小 Tag）。
5. 底部导出区
   - 「导出licence授权」「导出人员授权」为描边按钮，「导出完整授权」为蓝底白字主按钮，全部方圆角、等宽满行。

## 交互

- 全部分区默认折叠（对应第三张图的效果），点击标题行整体展开/收起，右侧 chevron 旋转，展开使用高度过渡动画。
- 折叠状态下标题行显示对应计数（如 licences 5、人员 6）。
- 复制按钮写入剪贴板并弹 sonner 提示。

## 技术细节

- 新增可复用组件 `src/components/CollapsibleSection.tsx`（基于现有 SectionCard 样式 + 受控 open 状态）。
- 数据放 `src/data/mock.ts`：`projectLicenses`、`projectMembers`、`projectImportTabs`。
- 复用 `Tag`、`surface-card`、`bg-blue-2` 等既有 token，不新增颜色变量。
- 新页面自带 head() 元信息（标题 / description / og）。
