# 历史工单卡片 → 工单详情页

## 现状

历史工单卡片已经是 `<Link to="/tickets/$id">`，路由 `/tickets/$id` 已存在并能打开工单详情页。所以缺的不是路由本身，而是详情页内容与参考图不一致（缺少讨论区的真实对话、引用消息、已读状态、底部操作条等）。

## 要做的改动

文件：`src/routes/tickets.$id.tsx`（沿用现有黑白灰 + 蓝色点缀风格）

1. 顶部信息区
   - 标签行：状态、优先级、类型、工单号，与参考图一致。
   - 标题加粗；下方「所属项目 / 创建时间 / 最晚解决时间」用 label-value 行。
   - 发起人 → 处理人一行（头像 + 姓名，中间蓝色箭头）。

2. 问题描述、附件（缩略图卡片）、讨论摘要 三个卡片，保持现有 surface-card 样式。

3. 讨论区（重点补齐）
   - 标题「讨论（N）」+ 在线人数。
   - 按时间分组的居中时间胶囊。
   - 我方消息右侧浅蓝气泡（右下角尖）、对方消息左侧白底气泡带头像与「姓名 + 时间」。
   - 支持引用消息块（左侧蓝色竖线 + 被引用内容）。
   - 消息底部「已读」小字。
   - 底部输入区：`@U老师` 标签、输入框、附件按钮、发送按钮。

4. 底部操作条
   - 「催办 / 上报 / 编辑」三个方圆角按钮，描边浅灰风格，置于讨论卡片下方。

5. 讨论数据放到 `src/data/mock.ts`（按工单 id 提供示例对话），保证从历史工单任意卡片进入都能正常渲染。

## 验收

- 从历史工单点击任意卡片进入 `/tickets/#id` 对应详情页。
- 详情页结构与参考图一致，配色仍为黑白灰 + 蓝色点缀。
- 构建通过。
