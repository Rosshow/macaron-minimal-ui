# 项目详情信息（信息树）

把现有的「项目详情」页替换成一棵可折叠的项目信息树，手机优先、单列、浅蓝卡片风格。内容存在云端，所有人共同维护同一份；无需登录即可读写。

## 页面结构

- 顶部：项目标题 + 返回。
- 标签池：12 个一级标签横向排布（基础信息、车辆、车端软件、调度软件、服务器信息、环境、业务系统、业务流程、人员、特性、项目配置、项目定制），可多选，选中后只显示这些标签及其全部子内容；不选则全部显示。附「全选 / 清空 / + 新标签」。
- 信息树：每个一级标签是一张卡片，卡片内按层级缩进展示它的子节点。
- 节点行：左侧折叠箭头（有子节点时）、标题、右侧内容区、右端「+」与「更多」（改名、改内容形式、删除）。
- 层级配色：一级最深蓝、二级中蓝、三、四级浅蓝到近白，文字色自动保证可读。
- 最多 4 层；在第 4 层点「+」时提示「信息维度过深，建议拆分或合并」，不生成第 5 层。

## 交互

- 新增子节点：任意节点「+」直接在其下插入一个可编辑的新节点，标题即刻进入编辑态。
- 拖动改从属：长按约 0.4 秒进入拖动态（卡片微微抬起），拖到某节点上松手成为其子节点；拖到两节点之间的缝隙则同级排序。拖动中高亮目标位置，禁止拖到自己的后代下，超过 4 层的落点不接受。
- 折叠状态与选中的标签是个人偏好，存本机；节点内容与结构存云端，所有人共享。

## 节点内容的四种形式

文字（多行）、下拉选择（选项由用户自行增删）、上传文件（文件名 + 大小，可下载）、上传图片（缩略图，点击放大）。一级与二级节点只能用文字，其余选项在菜单里置灰。

## 首屏内容

首次打开即带一套预设结构（按参考图）：基础信息（客户信息、订单信息 → ERP、评审信息、项目地址、进厂要求 → 着装/预约信息）、硬件（车辆 → 车型/数量，载具类型 → 托盘/料笼）、车端软件、调度软件、服务器信息、环境、业务系统、业务流程、人员信息、项目特性、项目配置、项目定制。

## 技术说明

- 开启 Lovable Cloud。建 `project_nodes` 表：`id、project_code、parent_id、title、content_type、value、sort_order、created_at`，公开可读可写策略并配好访问授权；迁移里直接写入预设结构的种子数据。
- 图片与文件存云端存储桶（公开读），节点只存链接与文件名、大小。
- 读写走 TanStack Query + 服务端函数，编辑乐观更新，保存后重新拉取同步多人改动。
- 树结构 `{ id, title, children, contentType, value, collapsed }`，扁平 map + 父子引用，便于拖动重挂。
- 拖拽用原生 Pointer 事件 + 长按计时，不引入新依赖。
- 层级配色在 `src/styles.css` 定义为 `--tree-depth-1..4` 语义 token，组件只用语义类名。
- 页面：改写 `src/routes/projects.$id.tsx`（保留原路由与入口），拆出 `src/components/tree/*` 组件；该路由自带独立 head 元信息。
