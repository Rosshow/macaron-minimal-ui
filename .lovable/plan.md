# 提单页：把「远程方式」换成「问题共享文档设置」

## 背景
「我要摇人」对话页点右下角「转工单」后，弹出「确认工单信息」提单表单。这个表单目前还没有做，本次按截图实现，并把其中的「远程方式」一栏替换为「问题共享文档设置」。

## 要做的事

### 1. 提单表单（点「转工单」弹出）
从底部弹出的表单，字段依次为：
优先级标记、工单类型、标题、描述、优先级、处理阶段、当前阶段截止时间（1天/3天/5天/7天/14天快捷选择 + 日期）、**问题共享文档设置**、绑定项目（必选，含「我的项目不在所属项目集中」勾选项）、底部「取消 / 确认提交」。

### 2. 问题共享文档设置（替换原「远程方式」）
- 一个可多选的「项目背景信息」选择器，选项就是所绑定项目详情页的信息标签（车辆、环境、人员、项目配置等一级标签），从云端项目信息读取。
- 未选择绑定项目时该项不可用，提示「请先选择绑定项目」；换项目后已选标签清空。
- 已选标签在下方以小标签形式展示，可单个移除。
- 下面一行「打开共享文档」入口，显示当前已引入的背景信息条数。

### 3. 在线共享文档
- 点开后全屏打开一份 Markdown 原格式文档，可直接编辑。
- 文档开头是自动生成的「项目背景信息」区块：按勾选的标签，把该标签及其全部子节点内容转成 Markdown 标题与正文；勾选变化时这一段自动同步更新。
- 自动区块下面是「问题背景补充」区域，用户自己写的内容不会被自动更新覆盖。
- 提供预览/编辑切换与「完成」返回表单，返回后表单显示文档摘要。
- 本期文档只存在当前页面（示例态），刷新后回到初始内容。

## 技术说明
- 新增 `src/components/ticket/TicketCreateSheet.tsx`（表单）、`SharedDocDialog.tsx`（Markdown 编辑器）、`shared-doc.ts`（由项目节点生成 Markdown 的纯函数）。
- 项目标签与子节点复用现有 `getProjectNodes`（`src/lib/project-tree.functions.ts`）+ TanStack Query；项目下拉复用 `src/data/mock.ts` 的 `projects`。
- 在 `src/routes/index.tsx` 里给 `FloatingTicketButton` 的 `onClick` 接上弹层，其他对话逻辑不动。
- 文档状态用组件内 state；自动段落与手写段落用固定分隔标记区分，重算时只替换自动段。
- 沿用现有极简黑白灰 + 蒂芙尼蓝语义色与 shadcn 组件，手机优先单列。

## 验收
- 点「转工单」弹出完整表单；「远程方式」不再出现，取而代之是「问题共享文档设置」。
- 选好项目后可多选该项目的信息标签，可打开 Markdown 文档看到这些背景信息并继续编辑补充。
