# 项目详情页：四张卡片

把项目详情页整理成四张卡片：项目概况、项目详细信息、项目工单、项目动态。工单与动态先用示例数据填充，界面与交互先做完整。

## 1. 项目概况（第一张卡片）

- 卡片加标题「项目概况」。
- 现有字段（客户信息、项目经理、对接人、编号、企微记录号、进度、部署/近期/最终交付、标签、紧急度）保持不变。
- 底部新增一行三列：AGV 数量、USP 版本、「搬运效率分析」按钮（从原位置移到这里）。AGV 数量与 USP 版本给示例值，点击可就地修改。
- 再下面一行：AI 项目摘要，示例文案，折叠展示，过长可展开。

## 2. 项目详细信息（第二张卡片）

- 标题旁原「+ 新标签」的位置改为「编辑」按钮，跳转到一个独立的编辑页面，在那里集中管理所有节点：新增、改名、改内容形式、删除、拖动调整从属。
- 详情卡片本身变为浏览态：顶部保留「显示内容」标签池（含全选/清空），用户勾选要看的根标签。
- 勾选后渲染这些标签及其全部子节点，节点以 Markdown 文档格式展示（标题层级对应节点层级、内容按 Markdown 语法排版，文件/图片以附件形式呈现），不再用卡片嵌套。
- 编辑页每个节点的编辑按钮旁增加「历史」按钮，点开弹层显示「谁 / 什么时候 / 改了什么」，本期先用示例记录展示样式。

## 3. 项目工单（第三张卡片）

- 标题「项目工单」，右侧一个「全部工单」按钮，进入工单列表页。
- 标题下一行统计：全部 12、待处理 3、处理中 5、已关闭 4。
- 核心阻滞问题区：问题标题、工单号（如 #789）、提单人、接单人、问题概况。
- 风险问题区：高/中/低三档及各自数量。
- 「全部工单」页里除了列表，还能看出工单之间的关系：父子工单以缩进层级展示，前置/后置工单在卡片里成对标注并可跳转。

## 4. 项目动态（第四张卡片）

三个小区块，均用示例数据：

- 调度版本变更：版本号 + 时间 + 变更说明的时间线。
- 工单增加变化趋势：近几个月新增工单数的小柱状图。
- 项目阶段变化：阶段流转记录（从哪个阶段到哪个阶段、时间）。

## 技术说明

- 页面：`src/routes/projects.$id.tsx` 组装四张卡片；新增 `src/routes/projects.$id.edit.tsx`（信息树编辑页）与 `src/routes/projects.$id.tickets.tsx`（全部工单页），两页都带独立 head 元信息。
- 拆分现有 `src/components/tree/ProjectInformationTree.tsx`：浏览态（只读渲染 + 标签筛选）与编辑态（现有增删改、拖动、历史按钮）分成两个组件，共用节点渲染与云端读写逻辑，数据表结构不变。
- 工单、动态、编辑历史的示例数据放进 `src/data/mock.ts`，接真实数据时只换数据源。
- 概况新增字段（AGV 数量、USP 版本、AI 摘要）先存本地状态 + 示例值，样式复用 `src/components/ProjectDetailBits.tsx` 已有字段模式。
- 柱状图复用现有 `src/components/MonthBars.tsx`。
