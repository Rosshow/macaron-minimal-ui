# 对话气泡交互按钮

## 目标
在首页 `/` 的对话气泡下方增加轻量交互按钮，提升对话可操作性。

## 改动范围
仅修改 `src/routes/index.tsx` 的消息渲染区域，不改动其他页面与全局样式。

## 具体方案

### 1. 左侧气泡（AI / 助手消息）
在气泡下方左侧显示三个图标按钮：
- 点赞（ThumbsUp）
- 点踩（ThumbsDown）
- 复制（Copy）

### 2. 右侧气泡（用户消息）
在气泡下方右侧显示两个图标按钮：
- 复制（Copy）
- 编辑（Pencil）

### 3. 视觉规范
- 按钮组位于气泡正下方，与气泡间距约 4px
- 按钮为纯图标按钮，尺寸约 22px
- 默认状态：浅灰色图标（`text-muted-foreground`）
- 悬停/激活状态：图标变为深灰或主色蓝
- 按钮排列方向：左侧气泡按钮左对齐，右侧气泡按钮右对齐
- 保持整体极简风格，不增加背景色块或边框

### 4. 行为
- 复制：将气泡文本写入剪贴板
- 点赞 / 点踩：切换本地激活状态（仅前端状态）
- 编辑：将文本回填到输入框（如输入框存在）

## 验收标准
- [ ] 左侧气泡下方显示点赞、点踩、复制三个按钮
- [ ] 右侧气泡下方显示复制、编辑两个按钮
- [ ] 按钮样式与现有极简黑白灰 + 蒂芙尼蓝点缀风格一致
- [ ] 构建通过，无 TypeScript 错误
