# 系统任务页：关系列表（父子缩进树 + 前后置流程轨道）

保留现有页面框架、搜索、筛选、排序和卡片风格，只增强列表的关系展示。仅前端示例数据，不接后端，不加新建/派单/编辑。

## 1. 视图切换
- 筛选区下方加分段按钮「普通列表 / 关系列表」，另有「全部展开 / 全部折叠」。
- 普通列表：沿用现有平铺+排序；有父工单的子工单在卡片底部多一行低强调文字「所属：#100 项目上线」。
- 关系列表：顶部轻提示「当前按工单关系组织，组内按依赖顺序展示」，箭头旁图例「箭头表示前置 → 后置」。

## 2. 父子关系（缩进树）
- 父卡片左侧展开/折叠按钮（aria-expanded），显示「子工单 1/3 已完成」。
- 子卡片缩进、浅灰无箭头树线（├ └），卡片略紧凑但完整可点击。
- 支持多层；超过 2 层后缩进减小，保证手机端内容宽度。
- 折叠时隐藏子工单及其内部依赖线，保留进度摘要。

## 3. 前后置（左侧流程轨道）
- 同级卡片左侧独立轨道：节点圆点 + 向下箭头；前置已完成=实线并带「✓已满足」图标，未完成=虚线 + 橙色「前置未完成」文字提示。
- 只连接真实依赖边，不因相邻自动连线。
- 独立依赖链包成可折叠展示组：「依赖链 · 3张工单 · 1张处理中」（仅展示容器，不是新工单）。
- 汇合：多个前置各自连线汇入后置（并行，不画成串行）；前置区可折叠：「前置工单 · 2张 · 1张未完成」。分叉同理。
- 每张工单只渲染一张完整卡片。
- 点击卡片选中：其直接依赖线高亮，其余线降低透明度。
- 父子组内有依赖时：树线（灰、无箭头）和流程轨道（带箭头）分开位置与样式。

## 4. 跨组依赖
- 卡片内短入口「↗ 前置：#405 数据迁移 · 定位」，不画长线。
- 定位：展开目标所在组 → 滚动 → 短暂高亮 → 浮出「返回原位置」按钮。
- 目标不在当前筛选中：提示「该工单不在当前筛选结果中」并提供「查看全部」按钮（不偷偷清筛选），且不显示目标标题/人员。

## 5. 状态与交互
- 工单状态（处理中等）与依赖提示（前置条件未满足）分开显示；前置未完成仅提示「暂不可完成」，不禁止查看。
- 折叠按钮、定位入口点击不触发打开卡片；全部按钮可键盘操作。
- 轻量展开动画，尊重「减少动态效果」设置；不依赖鼠标悬停。

## 6. 示例数据（覆盖 6 种场景）
独立工单；纯父子组；三张简单依赖链（#201→#202→#203）；两前置汇合（#301、#302 → #303）；父子组内含依赖（#100 下 #101→#102→#103）；跨组依赖（依赖 #405 所在组）。状态覆盖待处理/处理中/已完成。

## 技术说明
- 新增 `src/data/task-relations.ts`：工单 + 结构化 `parentEdges` / `dependencyEdges`。
- 新增 `src/lib/task-graph.ts`：分组（父子树、依赖连通块）、组内拓扑排序、摘要计算；配小测试验证排序与汇合不被判成串行。
- 新增 `src/components/tasks/RelationList.tsx`：渲染组/卡片；流程轨道用 SVG 叠层，按卡片实际位置（ref + ResizeObserver）计算连线，折叠、高度变化、窗口缩放后自动重算。
- `tasks.tsx`：加视图切换，复用并扩展现有 `TicketCard`（所属父工单行、依赖提示、关注按钮）。
- 颜色使用已有语义 token，新增一个橙色 warning token。
