# 系统任务页：关系列表（缩进 = 父子，单向箭头 = 依赖）

保留现有页面框架、搜索、筛选、排序和卡片风格。仅前端示例数据，不接后端，不加新建/派单/编辑。

## 核心规则
- 父子关系只用缩进：桌面每层 24px，手机 16px；同层左边缘对齐；子卡片字号不缩小。不画任何树线、括号或容器框。
- 依赖关系只用单向箭头：前置 → 后置，箭头头只在后置端；细线、低饱和蓝色，走卡片右侧预留的连线区，不穿过标题和按钮。无圆点、无步骤条、无编号。
- 只连真实依赖；相邻但无依赖不画线；依赖工单不缩进。

## 1. 视图切换
- 筛选区下方：「普通列表 / 关系列表」+「全部展开 / 全部折叠」。
- 普通列表保留原排序。
- 关系列表保持父子结构，在同一父工单内按依赖顺序排列；绝不把子工单移出父工单。

## 2. 父子折叠
- 只有真实父工单有折叠按钮（加号/减号图标，aria-expanded），显示「子工单 1/3 已完成」。
- 折叠隐藏全部后代及其内部箭头；嵌套折叠，重新展开时保留内部状态。
- 不为依赖链虚构父工单或分组。

## 3. 箭头绘制
- 多前置 → 同一后置、一前置 → 多后置：每条依赖一根独立箭头，错开走线减少交叉，不加汇合/分叉节点。
- 跨组依赖用外侧折线单向箭头，可向上。
- 点击卡片：其直接依赖箭头高亮，其余降低透明度；点空白恢复。
- 端点被折叠：不改接到父工单，隐藏该箭头，在可见一端显示轻量提示「有依赖工单被折叠」，点击展开真实端点并滚动定位。
- 端点不在当前筛选结果中：不画悬空箭头，显示「依赖工单不在当前结果中 · 查看」入口。

## 4. 卡片与状态
- 保留编号、标题、状态、优先级、创建人、处理人，新增关注按钮。
- 业务状态与依赖状态分开显示（如「前置未完成」小字提示），不禁用操作。
- 折叠按钮、提示入口点击不打开卡片；全部可键盘操作，不依赖鼠标悬停。

## 5. 示例数据（8 种场景）
独立工单；纯父子组；多层父子；三张同级依赖链；父子组内依赖（#100 下 #101→#102→#103）；两前置指向同一后置；一前置指向两后置；跨父子组依赖。状态覆盖待处理/处理中/已完成。

## 技术说明
- `src/data/task-relations.ts`：工单列表 + 结构化 `parentEdges`、`dependencyEdges`。
- `src/lib/task-graph.ts`：构建树、同父兄弟间拓扑排序（并行保持并列）、可见性与箭头端点判定；配测试（并行不成串行、折叠端点不改接、子工单不移出父工单）。
- `src/components/tasks/RelationList.tsx`：缩进渲染卡片；整列表 SVG 叠层，按卡片真实位置（ref + ResizeObserver + resize）计算箭头，展开/折叠/缩放后重算；尊重减少动态效果设置。
- `tasks.tsx`：加切换与按钮，复用现有 `TicketCard` 并加关注按钮。
