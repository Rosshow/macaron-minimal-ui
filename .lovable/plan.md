# 工单卡片标题与类型对齐优化

## 目标
调整系统任务页工单卡片的标题与右上角工单类型文字：标题字号加大一号，且两者顶部对齐。

## 具体改动

### 1. 重构 `TicketCard` 头部布局
文件：`src/routes/tasks.tsx`

将当前上下排列的标题（`h3`）与工单类型（`span`）改为同一行 flex 布局：
- 左侧为标题，右侧为工单类型
- 使用 `items-start` 让两者顶部对齐
- 移除标题原有的 `mt-1`，因为不再位于类型下方

### 2. 调整字号
- 标题字号从 `text-[16px]` 增加到 `text-[17px]`
- 工单类型保持 `text-[11.5px]` 不变

## 验收标准
- 预览中工单卡片标题明显比当前大一号
- 右上角“问题/需求/功能”等类型文字的上沿与标题上沿在同一水平线
- 卡片其余信息（状态标签、参与人、项目编号、日期）保持原样
