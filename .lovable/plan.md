# 首页增加转工单悬浮按钮

## 目标
在首页右下角「新建会话」按钮上方增加一个悬浮的「转工单」按钮，方便用户快速将当前会话内容转为工单。

## 改动范围
仅修改 `src/routes/index.tsx` 的底部输入栏区域，不改动其他页面。

## 具体方案

### 1. 按钮位置
在现有底部输入栏右侧「新建会话」圆形图标按钮的正上方，新增一个同样大小的圆形悬浮按钮，与「新建会话」按钮保持约 8px 间距。

### 2. 按钮样式
- 形状：圆形，与「新建会话」按钮尺寸一致（size-10，约 40px）
- 背景：使用主色蓝（`bg-primary`）
- 图标：使用 `Ticket` 或 `ArrowRight` 图标，白色（`text-primary-foreground`）
- 阴影：与「新建会话」按钮一致，使用 `shadow-[var(--shadow-soft)]`
- `aria-label`："转工单"

### 3. 视觉层级
- 转工单按钮位于新建会话按钮上方，形成垂直堆叠
- 两个按钮右对齐，与发送按钮保持同一水平基准

### 4. 行为
- 点击后跳转至 `/history` 或触发转工单流程（本次仅实现 UI 占位，点击行为可后续接入业务逻辑）

## 验收标准
- [ ] 首页右下角「新建会话」按钮上方出现「转工单」圆形悬浮按钮
- [ ] 按钮样式与现有极简黑白灰 + 蒂芙尼蓝点缀风格一致
- [ ] 按钮与「新建会话」按钮垂直对齐，间距合理
- [ ] 构建通过，无 TypeScript 错误
