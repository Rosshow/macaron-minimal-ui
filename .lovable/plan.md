# 项目导入展开区按钮样式调整

## 目标
让「项目授权管理」页中「项目导入」展开后的两个选项按钮（USP项目 / 其他项目）与参考图保持一致：选中项为蓝底白字，未选项为白底蓝字蓝边。

## 具体改动
- 文件：`src/routes/projects.auth.$id.tsx`
- 位置：`项目导入` CollapsibleSection 内部的两列按钮
- 当前样式：选中为黑底白字，未选为浅灰底灰字
- 改为：
  - 选中：`bg-blue-2 text-white`
  - 未选：`bg-card text-blue-2 border border-blue-2`
  - 形状保持现有的方圆角 `rounded-md`
  - 字号、字重保持现有 `text-[13px] font-semibold`
- 可选：将「项目导入」CollapsibleSection 的 `defaultOpen` 设为 `true`，方便进入页面即看到这两个按钮

## 不变的部分
- 不新增路由或页面
- 不改动「项目授权 / licences 授权 / 人员授权 / 导出」等其他区块
- 不改动全局样式或设计系统
- 按钮交互逻辑（切换 `tab` 状态）保持不变

## 验收标准
- 进入项目授权管理页，展开「项目导入」后可见「USP项目」和「其他项目」两个按钮
- 选中项为蓝底白字，未选项为白底蓝字带蓝边
- 两按钮并排，宽度一致，间距合适
- 构建通过
