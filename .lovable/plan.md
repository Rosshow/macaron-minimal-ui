# 底部导航栏简化：去文字、放大图标

## 目标
将全站底部导航栏（我要摇人 / 系统任务 / 后台管理）从「图标+文字」改为「仅图标」，并适当放大图标，保持选中高亮与整体极简风格。

## 改动范围
- `src/components/Shell.tsx` 中的 `BottomNav` 组件

## 具体修改
1. 移除每个导航项下方的文字标签 `<span>{label}</span>`。
2. 将图标尺寸从当前 `size-[18px]` 放大至 `size-6`（24px），并相应增大外圈容器（从 `size-9` 调整至 `size-11` 或 `size-12`），使图标在底部栏中视觉更突出。
3. 为每个 `Link` 保留 `aria-label={label}`，确保可访问性不丢失。
4. 调整垂直内边距，使无文字后的底部栏高度合理、居中舒适。
5. 保持选中态背景色（`bg-blue-soft text-blue-2`）与非选中态（`text-muted-foreground`）不变；图标容器保持 `rounded-2xl`。

## 验收标准
- 底部栏三个入口仅显示图标，无文字。
- 图标尺寸明显大于当前，视觉重心适中。
- 点击跳转、选中高亮、安全区适配均保持原有行为。
