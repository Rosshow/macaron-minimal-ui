# 历史工单分类计数徽章

## 目标
在历史工单页顶部的状态分类标签（全部 / 新建 / 处理中 / 待处理 / 已解决 / 已取消 / 已关闭）右侧增加计数徽章，采用灰底白字样式。

## 实现方案

1. **计算各状态数量**
   - 在 `src/routes/history.tsx` 中基于 `tickets` 数据，按 `status` 统计每个分类的工单数量。
   - "全部" 显示总数量，其余分类匹配对应 `status`。

2. **标签按钮增加徽章**
   - 在每个分类按钮内部右侧增加一个小型计数徽章。
   - 徽章样式：圆角小标签、灰色背景、白色文字、与按钮文字保持合适间距。
   - 选中态与非选中态下徽章颜色保持一致（灰底白字），避免视觉跳动。

3. **保持现有交互与滚动**
   - 保留横向滚动布局。
   - 保留当前选中态的黑底白字高亮逻辑。

## 涉及文件
- `src/routes/history.tsx`
