# 项目授权：先选项目，再授权

参考图的流程是：项目授权区块里先选择项目，选中之前 licences 授权和人员授权都不可用。现在页面默认展示了固定项目和数据，需要改成选择驱动。

## 交互流程

1. **项目授权**（默认展开）：一行「请选择项目」选择器，右侧箭头。点击弹出项目选择列表（底部抽屉），可搜索、单选。选中后该行显示项目名 + 项目代码，可再次点击更换。
2. **项目 licences 授权**：未选项目时，展开内容为居中灰色占位文字「请先选择项目」，标题右侧不显示计数。选中项目后显示该项目的授权记录列表 + 申请授权码表单。
3. **项目人员授权**：同样逻辑，未选项目显示「请先选择项目」，选中后显示已关联人员列表与「+ 添加关联人员」。
4. **导出按钮**：未选项目时三个按钮置灰不可点击（降低透明度、cursor-not-allowed）；选中项目后恢复正常。
5. 更换项目时，licences 与人员数据随之切换。

## 视觉

沿用现有风格：黑白灰为主，蓝色只用于主按钮（申请授权码、导出完整授权）与选中态。选择器为浅灰底方圆角行，占位文字用 muted 灰色。

## 技术说明

- 仅改动 `src/routes/projects.auth.$id.tsx`，新增本地 `selectedProject` 状态。
- Mock 数据扩展为按项目 code 分组的 map（2-3 个项目），未选中时为空。
- 项目选择使用现有 shadcn `Sheet`（与 HistorySessions 一致）实现底部/侧边选择列表，避免引入新依赖。
- 「项目导入」区块保持现状不变。
