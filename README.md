# Soft Glow Pages

这是一套H5的html打开页面，帮我美化一下前端的UI，要求：
1.色彩和设计要统一，并且都使用低饱和的马卡龙配色
2.字体圆润，不要太尖锐
3.整体极简风格，用色克制
4.给人高级又有科技感的感觉
